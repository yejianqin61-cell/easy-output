# Easy diagram（中文对照）

本文件是 [`SKILL.md`](SKILL.md) 的中文对照，供人阅读，运行时不起作用。

**图是画出来的一个判断。** 动手之前先把判断写成一句话。写不出来，说明你要的是两张图。

那句话既是方法也是判据。一张没法用一句话概括的图，是"某个话题的图"，读者不知道该看哪里。

## 流程

五步。每步结束在一个你能验证的判据上。

### 1. 写出判断

一句话，带动词、带方向："重试把 p99 延迟翻了一倍""只有 leader 接受写""状态不需要用户动作就会离开 open"。

**完成判据**：句子有主语、动词、方向。"重试逻辑概览"三样都没有，它不是判断。

### 2. 看关系选类型

| 关系是 | 类型 | 注意 |
|---|---|---|
| 发生了什么、按什么顺序 | 流程图 | 只用一个方向 |
| 谁跟谁说话、按什么顺序 | 时序图 | 时间在纵轴 |
| 一个东西会变状态 | 状态机 | 每条转移都带事件标签 |
| 什么包含什么 | 树 | 深度就是含义，不要装饰深度 |
| 什么连着什么 | 图 / 网络 | 先聚类，或停在 12 个节点 |
| 实体怎么关联 | ER 图 | 两端标基数 |
| 什么时候变了什么 | 时间线 | 顺序与时长才是内容 |
| 系统为什么这样表现 | 因果回路 | 边标 `+` / `−` |
| 哪个选项在哪个维度赢 | 对比矩阵 | 超过三个维度就比柱状图好 |
| 一个量与另一个量 | 坐标图 | 轴、单位、标题里写结论 |

**完成判据**：只选中一行，没有第二种类型混进来。

### 3. 选载体

在对话里说：**ASCII**。要留在仓库里：**Mermaid**。会被反复查看或探索：**独立 SVG**。动手前读
[references/carriers.md](references/carriers.md) 里对应那一节，另外两节跳过。

**完成判据**：载体点名了，而且当前环境能渲染或显示它。不能，就退到一个你能检查的更朴素的载体。

### 4. 画

- 每条边都是一句话。没有动词的箭头就该删掉。
- 一张图一个流向。两个流向交叉就是两个面板。
- 顶层节点最多 12 个。超了就聚类，或者拆成总览 + 细节两张。
- 同一个东西到处用同一个标签，跟代码里也一致。
- 颜色不能单独承载含义：加形状、虚线或标签，并给图例。
- 留白是功能。先用容器分组，再给容器之间留白。
- 标注那个要紧的节点。这个标注才是把图变成解释的东西。

**完成判据**：每个标签读者都认得，且没有任何含义只靠颜色表达。

### 5. 自检

- 它渲染得出来。Mermaid：渲染一遍。SVG：打开它。ASCII：看列对齐。
- 把图念出来，能复现第 1 步那句判断。
- 图注写的是结论，不是话题："重试把 p99 延迟翻了一倍"，而不是"重试示意图"。

**完成判据**：三条都在你要交出去的那份东西上成立。

## 放进文档，还是本身即产物

放进 Markdown 文档时，图就待在它替掉的那几段话的位置，用 Mermaid 围栏或 ASCII 代码块，配图注。
要独立成页，就调用 Skill 工具并传入 "easy-report"，把 SVG 放进 `figure.diagram`：页面会带上主题、
打印样式表和无障碍的接线。

内容本身是定义或事实清单时，文字是更便宜的载体。一张重复散文的图，是让读者多付了时间。

## 反模式

- 毛线球：40 个节点、80 条边，毫无分组。
- 没人渲染过的 Mermaid，读者看到的是源码而不是图。
- 装饰深度：阴影、渐变、3D，什么都没编码。
- 只靠颜色表意。
- 图重复散文，而不是压缩散文。
- 坐标图不标轴。
- 内容本来是定义，却画了图。文字是更便宜的载体。
