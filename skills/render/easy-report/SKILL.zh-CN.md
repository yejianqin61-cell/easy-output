# Easy report（中文对照）

本文件是 [`SKILL.md`](SKILL.md) 的中文对照，供人阅读，运行时不起作用。

报告是同一份文档，为"读"而渲染，不为"改"。它加的是导航与易读性，不加任何新主张。

页面是**填出来的，不是设计出来的**。复制
[references/report-template.html](references/report-template.html)，替换它的槽位，`<style>` 块一个字
都别动。成品页约 60% 是那张样式表，它就是"看起来讲究"的原因。手写 CSS 会做出一个能打开但读起来很糟的页面，
因为每一个视觉决定都在跟其他决定打架。

## 流程

五步。每步结束在一个你能验证的判据上。

### 1. 指明源文档

报告渲染的是一份已经存在的文档。指出它的路径。还没有文档就先写文档：这个 skill 只做渲染，不做决定。

**完成判据**：源路径存在，而且你读过它。

### 2. 复制模板

`cp references/report-template.html ./<slug>.html`。

**完成判据**：副本能在浏览器里打开，显示占位页。

### 3. 填槽位

照 [references/fill-in-contract.md](references/fill-in-contract.md) 做：每个 `{{TOKEN}}`、每个
`<!-- SLOT -->`、类词表、以及插入内容的规则。不需要的槽位删掉，其余别动。

**完成判据**：`grep -c '{{' <slug>.html` 与 `grep -c '<!--' <slug>.html` 都返回 0。

### 4. 事实保持一致

判定逐字照抄。数字、状态、表格都一致。跟所渲染文档打架的报告，比没有报告更糟，因为读者信更漂亮的那一份。

**完成判据**：页面里每一条主张都能在源文档里找到；没有只存在于页面里的主张。

### 5. 打开它

从 `file://` 在真实浏览器里打开。查暗色模式、查打印预览、查 375 px 窗口。跑
[references/verify.md](references/verify.md) 的闸门。

**完成判据**：你要交出去的那份文件通过了闸门。

## 交付

给出路径和打开方式。不要在对话里复述文档。

## 反模式

- 自己写 CSS。回到丑页面最快的一条路。
- 发明类词表以外的类名。它们渲染成无样式文本。
- 交付时文件里还留着 `{{` 或 `<!--` 标记。
- 为页面重写判定或数字，弄得两个版本互相打架。
- 加了源文档里没有的表格：一条没人审过的新主张。
- 条形图没有 `--max`，或者坐标轴不从零开始。
